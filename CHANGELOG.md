## [1.0.0] — 2026-10-19

Первый официальный выпуск.

### Публичный сайт
- Главная — презентация платформы: первый экран и главы «Клиенту», «Складу», «Менеджеру», «Цифры», затем «Где мой груз», расписание, частые вопросы и контакты.
- Расписание машин: рейсы в погрузке и в пути (и прибывшие за 3 дня), маршрут Уссурийск — Владивосток, дата отправки, ожидаемое прибытие, прогресс рейса. Без данных клиентов.
- «Где мой груз»: поиск по коду клиента или артикулу и последним 4 цифрам телефона, ограничение числа попыток с одного адреса.
- Контакты склада: адрес, часы работы, телефон, ссылка на карту.
- Вход для сотрудников с переходом в нужный раздел панели по роли.

### Telegram-бот
- Привязка клиента по ссылке (QR-коду) или по номеру телефона.
- Меню: «Мои грузы», «Расписание машин», «Адрес и часы склада».
- Сообщения клиенту: машина выехала, груз на складе, напоминание, хранение заканчивается.
- Если клиент заблокировал бота, чат отвязывается, а груз попадает в ордер на звонок.

### Панель
- Светлая тема, роли «Менеджер» и «Склад».
- **Ops-центр**: показатели дня, конвейер статусов, схема маршрута с машинами, таймлайн отправок и прибытий.
- **Аналитика**: графики потока грузов, возраста грузов на складе, заполненности машин, звонков и времени в пути.
- **Машины**: создание, отправка и прибытие с подтверждением последствий (сколько клиентов получат сообщение, сколько попадёт в ордер).
  - Содержимое кузова: добавить принятые грузы, создать новый, убрать груз из машины, пока она грузится; массовый выбор; индикатор заполненности (места, вес, клиенты).
  - Импорт манифеста из Excel с редактируемым предпросмотром: исправить ячейку, удалить или добавить строку перед сохранением; загрузка атомарная.
  - Ручной ввод грузов в той же редактируемой таблице.
- **Грузы**: поиск и фильтры, в том числе по сроку на складе; сводка по фильтру (количество, места, вес, сумма); карточка груза с историей статусов, уведомлениями и звонками; редактирование полей; массовые действия — погрузить в машину и выгрузить в Excel.
  - Новые поля груза: трек-номер, продавец, упаковка, хрупкое, заметка, фото. Импорт принимает их как необязательные колонки.
- **Клиенты**: поиск по телефону, коду и имени; создание клиента; карточка с кодом, ссылкой и QR-кодом для подключения бота.
- **Склад** с вкладками:
  - «Выдача» — поиск клиента по коду, телефону или артикулу и выдача нескольких грузов сразу с отметкой оплаты;
  - «Ордер на звонок» — см. ниже;
  - «На складе» — остатки по блокам A–D с возрастом и местами.
- **Автопилот** (только менеджер): симулятор для демонстрации, который создаёт рейсы, принимает и грузит грузы, отправляет и принимает машины, выдаёт часть грузов и формирует ордер. Старт и пауза, скорость ×1/×10/×60, «Один шаг», журнал действий; фоновая команда `autopilot --loop`. Выключается настройкой `AUTOPILOT_ENABLED`.

### Уведомления и ордер на звонок
- Уведомления ставятся в очередь в той же операции, что и смена статуса; отправку делает отдельная команда `send_notifications`. Без токена бота — режим проверки без отправки.
- Ежедневные напоминания `daily_reminders`: о лежащем грузе и об окончании бесплатного хранения.
- Ордер на день (`build_daily_order` или кнопка в панели): только те, кому нужно позвонить — нет Telegram, сообщение не дошло, груз долго лежит, прошлый звонок без ответа.
- Отметки «Позвонили» (с датой приезда и комментарием) и «Не дозвонились» без перезагрузки страницы, счётчики, фильтр, печать на A4 и выгрузка в Excel; прошлые ордера только для чтения.

### Инфраструктура
- Python 3.12, Django 5.1, шаблоны Django + HTMX, CSS на токенах.
- SQLite для разработки, PostgreSQL в продакшене; настройки из переменных окружения (`.env.example`).
- Демо-данные: `seed_demo`.
- Инструкция по установке на VPS: PostgreSQL, gunicorn, nginx, HTTPS, systemd-службы и таймеры, резервные копии (`docs/DEPLOY.md`).
- Тесты pytest и линтер ruff; автоматическая проверка на GitHub Actions.
- Инструкция по публикации на GitHub (`docs/GITHUB.md`).
